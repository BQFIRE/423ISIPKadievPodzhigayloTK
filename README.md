# WPF приложение расчёта стоимости билетов

## Описание
Приложение разработано на C# с использованием WPF.  
Позволяет рассчитать стоимость железнодорожных билетов в зависимости от расстояния, количества билетов и типа вагона.

## Функционал
- Ввод расстояния (км)
- Ввод количества билетов
- Выбор типа вагона:
  - Плацкарт
  - Купе
  - Полулюкс
  - Люкс
- Расчёт итоговой стоимости

## Формула расчёта
Стоимость = расстояние × 8 × коэффициент × количество билетов

Коэффициенты:
- Плацкарт — 1.0
- Купе — 1.1
- Полулюкс — 1.2
- Люкс — 1.3

## Тестирование
Для проекта реализованы unit-тесты (MSTest).  
Проверены корректные расчёты и обработка ошибок.  
Все тесты успешно пройдены.

## Технологии
