В рамках второй части практической работы в проект WPF-приложения из практической работы №4 был добавлен проект модульных тестов UnitTestProject.

В тестовом проекте были реализованы модульные тесты для страниц приложения:
- Test_Page1 — проверка создания страницы Page1;
- Test_Page2 — проверка создания страницы Page2;
- Test_Page3 — проверка создания страницы Page3.

В каждом тесте выполняется создание объекта соответствующей страницы и проверка его корректного создания с помощью метода Assert.IsNotNull.

Все тесты были успешно выполнены, что подтверждает корректность работы страниц приложения и отсутствие ошибок при их инициализации.

## Вывод

В ходе выполнения практической работы были изучены методы автоматизированного тестирования программного кода.

В первой части был создан класс BankAccount и реализованы методы Debit и Credit. С помощью модульных тестов была проверена корректность их работы. В процессе тестирования была обнаружена ошибка в методе Debit, после чего она была исправлена. После исправления все тесты успешно прошли.

Во второй части были разработаны модульные тесты для трех математических функций из практической работы №4. Тесты подтвердили корректность работы функций.

Автоматизированное тестирование позволяет выявлять ошибки в программе и повышает надежность программного обеспечения.
