## Описание задания

В рамках практической работы было разработано WPF-приложение, состоящее из трёх страниц, каждая из которых реализует вычисление математических функций.

### Первая страница

Вычисляется значение функции:

```
v = ∛(8 + |x - y|² + 1) / (x² + y² + 2) - e^|x-y| · (tg²z + 1)^x
```

Пользователь вводит значения переменных `x`, `y`, `z`, после чего нажимает кнопку «Вычислить», и результат отображается в поле вывода.

---

### Вторая страница

Вычисляется кусочная функция:

```
b = {
    ln(f(x)) + (f(x)^2 + y)^3, если x/y > 0
    ln|f(x)/y| + (f(x) + y)^3, если x/y < 0
    (f(x)^2 + y)^3, если x = 0
    0, если y = 0
}
```

Функция `f(x)` выбирается пользователем с помощью переключателей:

* sh(x)
* x²
* e^x

---

### Третья страница

Вычисляется функция:

```
y = 1.2(a - b)^3 · e^(x^2) + x
```

На заданном интервале `[x0, xk]` с шагом `dx`.

Программа:

* выводит таблицу значений
* строит график функции

## Архитектура приложения

Приложение состоит из следующих компонентов:

* `MainWindow` — главное окно с навигацией
* `Page1` — вычисление первой функции
* `Page2` — вычисление кусочной функции
* `Page3` — вычисление функции с построением графика

Навигация между страницами реализована через элемент `Frame`.
